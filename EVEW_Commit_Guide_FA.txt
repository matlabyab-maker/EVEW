راهنمای ساخت مخزن تازه EVEW با GitHub و MGit

۱) آماده‌سازی فایل‌ها
- فایل EVEW_0.2.199_CLEAN.zip را استخراج کنید.
- خود پوشه EVEW را در MGit به‌عنوان ریشه پروژه انتخاب کنید؛ پوشه والد را انتخاب نکنید.
- فایل‌های settings.gradle.kts و build.gradle.kts و پوشه‌های app و .github باید مستقیماً داخل EVEW باشند.
- این بسته پوشه .git، تاریخچه Git و Remote قبلی ندارد؛ مخزن محلی تازه بسازید.
- فایل‌ها و پوشه‌های مخفی را نمایش دهید و .github را نیز همراه بقیه فایل‌ها Stage کنید.

۲) ساخت مخزن در GitHub
- یک Repository خالی با نام EVEW بسازید؛ هنگام ساخت README یا فایل اولیه خودکار اضافه نکنید.
- آدرس HTTPS مخزن تازه را در MGit به‌عنوان Remote اضافه کنید.

۳) اولین Commit و Push
- همه فایل‌ها را، از جمله .github، Stage کنید.
- اولین Commit را ثبت و شاخه را به مخزن GitHub تازه Push کنید.

۴) بررسی GitHub Actions
- پس از Push، زبانه Actions را باز کنید و اجرای EVEW Android Build را بررسی کنید.
- فایل Workflow در مسیر .github/workflows/android.yml قرار دارد و در این بسته بدون تغییر نگه داشته شده است.
- اگر Build شکست خورد، متن کامل خطای همان اجرای جدید را ارسال کنید.

۵) نکته مهم درباره خطای R
- سورس Kotlin این بسته فقط در app/src/main/java/com/evew/app/MainActivity.kt قرار دارد.
- در این نسخه مسیر فیزیکی فایل Kotlin برای جایگزینی مستقیم فایل قدیمی حفظ شده است؛ اما package داخل فایل و namespace برنامه هر دو com.evew.app هستند. بنابراین مسیر پوشه به‌تنهایی نشانه وابستگی به EVC نیست.
- هنگام جایگزینی، فایل‌های پروژه قبلی را با فایل‌های این بسته ادغام نکنید؛ محتوای قبلی را کامل جایگزین کنید.
